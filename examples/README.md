# Examples

- `HOOK_WIRED.example.json` — shape of a call-hook wiring file (no absolute personal paths).
- `run_call_hook.example.sh` — sample post-call ingest script.
- `eval_results.example.json` — empty eval output structure; regenerate locally with `python -m phase1.cli eval --fixture`.

Personal runtime DBs and dumps are not shipped.
